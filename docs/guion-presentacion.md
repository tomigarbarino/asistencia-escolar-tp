# Guion de presentacion

## 1. Problema

La escuela registra asistencia de forma manual, lo que genera demoras, errores y dificultad para consultar informacion historica.

## 2. Objetivo

Crear un sistema que permita registrar asistencia diaria, cargar justificativos y generar reportes administrativos.

## 3. Alcance del MVP

El MVP cubre el circuito principal de asistencia escolar: curso, alumno, matricula, asistencia, justificativo y reporte.

## 4. Demo esperada

1. Mostrar backend activo.
2. Consultar cursos.
3. Consultar alumnos de un curso.
4. Registrar asistencia de una fecha.
5. Cargar un justificativo.
6. Ver reporte de asistencia.

## 5. Cierre

El sistema reduce carga manual, organiza la informacion y permite consultar reportes rapidamente.
